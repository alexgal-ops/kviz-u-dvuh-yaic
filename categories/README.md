# Как устроена категория

Каждая категория — один файл `categories/<id>.js`, подключается в `index.html` строкой
`<script src="categories/<id>.js"></script>` (порядок строк = порядок карточек). Картинки категории лежат в `img/<id>/`.
Образец — `categories/dota-cs2.js`. Проверка файла: `node tools/check-category.js categories/<id>.js`.

```js
KVIZ_CATS.push({
  id:"geografiya",                       // латиницей, совпадает с именем файла и папкой img/<id>/
  name:"География",                      // название на карточке
  sub:"Чудеса света, столицы, флаги и города", // одна строка под названием
  title:["Гео","графия"],                // заголовок заставки по строкам (1–3 строки)
  lead:"Одна-две фразы на заставке.",
  pics:["img/geografiya/a.jpg","img/geografiya/b.jpg"], // две картинки для карточки: левая обрезается до квадрата, правая вписывается
  tones:["ct","good"],                   // цвета раундов по очереди: dota (красный), cs (охра), ct (синий), good (зелёный)
  tags:{},                               // необязательно: плашки у вопросов {ключ:{label:"Европа", tone:"ct"}}, у вопроса поле g:"ключ"
  tiebreak:{q:"…", a:"…", note:"…"},     // перестрелка при ничьей: ответ — ЧИСЛО, побеждает ближайший
  rounds:[ /* 6 раундов, см. ниже */ ]
});
```

## Раунды — всегда шесть, в этом порядке

| # | kind | вопросов | time, с | pts | поля вопроса |
|---|------|---------|---------|-----|--------------|
| 1 | `choice` | 7 | 30 | `"1 балл"` | `q`, `o:[4 варианта]`, `a:индекс верного 0–3`, `note?` |
| 2 | `image` | 7 | 40 | `"1 балл"` | `q`, `img`, `fx`, `a`, `note?` |
| 3 | `emoji` | 7 | 40 | `"1 балл"` | `e:"эмодзи через пробел"`, `hint:"Город" / "Фильм" …`, `a`, `note?`; у раунда `breakAfter:true` |
| 4 | `open` | 7 | 45 | `"1 балл"` | `q`, `a`, `note?` |
| 5 | `bet` | 6 | 60 | `"ставка 1–3"` | `q`, `a`, `note?` |
| 6 | `box` | 3 | 30 | `"3 / 2 / 1"` | `hints:[3 подсказки от трудной к лёгкой]`, `a`, `img?` (показывается только на ответе), `note?` |

У каждого раунда: `name` (своё название раунда, можно тематичное), `kind`, `time`, `pts`, `intro` (1–2 фразы правил для заставки раунда), `qs`.
Тексты `intro` для `bet` и `box` бери из образца — там правила ставок и чёрного ящика.

### Эффекты картинок `fx` (раунд `image`)
- `{k:"blur", r:22}` — размытие, открывается на ответе. Для фото людей и мест. r 16–30.
- `{k:"pixel", b:N}` — пикселизация, N — размер блока в пикселях исходника. Хорошо, когда по ширине выходит 16–28 блоков: `b ≈ ширина / 22`.
- `{k:"zoom", x:50, y:30, s:3}` — крупный кусок картинки (x, y — точка в процентах, s — увеличение 2–4); на ответе — целиком.
- `{k:"plain"}` — картинка как есть (когда вопрос «что это», а сама картинка не выдаёт ответ сразу).
- `{k:"sil"}` — силуэт, только для PNG с прозрачным фоном.

## Правила содержания
- Публика русская, возраст 25–45. Все подписи, вопросы, ответы и пояснения — по-русски. Имена людей, названия мест, фильмов и брендов — как их пишут в русских СМИ (Илон Маск, Мачу-Пикчу).
- Каждый ответ проверен поиском, факт верен на октябрь 2026. Всё, что меняется со временем (кто сейчас у власти, рекорды, население), — проверить свежим источником или не брать.
- Источники — в `categories/<id>.sources.md`: номер раунда и вопроса → ссылка. Там же — сомнительные места.
- Сложность растёт: разминка лёгкая, ставки и чёрный ящик — заметно сложнее. Совсем очевидных вопросов не надо.
- В `note` — один короткий интересный факт, без воды.
- Варианты ответа (`choice`) — правдоподобные, одной длины, без шуточных «пустышек».
- Не повторять один и тот же факт в двух вопросах; ответ одного вопроса не подсказывает другой.

## Картинки
- **Никаких личных данных в запросах.** Ни почты, ни имени, ни логина пользователя — ни в User-Agent, ни в URL, ни в теле. Заголовок ровно `KvizBot/1.0 (home quiz)`. Ответ 429 — сделать паузу и повторить, заголовок не менять.
- Источники: Викисклад (upload.wikimedia.org), официальные сайты, крупные СМИ. Скачивать в `img/<id>/` через curl с заголовком
  `-A "KvizBot/1.0 (home quiz)"`. С Викисклада брать уменьшенную копию 1280px:
  `https://upload.wikimedia.org/wikipedia/commons/thumb/a/ab/File.jpg/1280px-File.jpg`.
- Каждый файл проверить: открывается как картинка (`file img/<id>/x.jpg`), весит до 600 КБ, на ней то, что нужно (посмотреть глазами через Read).
- Имена файлов латиницей, коротко: `kremlin.jpg`, `doge.jpg`.
- Картинка не должна выдавать ответ надписью (вывеска, подпись, водяной знак с названием).
